Pair this phone

The app needs your alarm's relay login once. It is stored only on this phone.

  1. Be on the shop's Wi-Fi and open the alarm's dashboard (http://shopalarm.local or its IP address).
  2. Tap Set up this phone for remote access and enter your PIN. This page opens again, paired.
  3. Then tap Share, then Add to Home Screen, so it opens like an app.
